# Versioning Policy

Project menggunakan Semantic Versioning.

Format:

MAJOR.MINOR.PATCH

Contoh:

1.0.0

- MAJOR → perubahan besar yang tidak kompatibel.
- MINOR → penambahan fitur.
- PATCH → perbaikan bug.
