# 📖 Overview

Portal Customer Service Digital is an internal web application designed to support customer service operations by digitizing complaint management and customer service workflows.

The application provides a centralized dashboard for monitoring complaints, tracking service status, and improving operational efficiency through Google Workspace integration.

---

# ✨ Features

## Customer Portal

- Online Complaint Form
- Complaint Tracking
- Customer Information Portal
- QR Code Access

## Internal Dashboard

- Complaint Statistics
- Real-time Dashboard
- Complaint Detail Viewer
- Google Drive Image Preview
- Status Management

## System

- Google Sheets Database
- Google Drive Integration
- Cache Optimization
- Responsive Dashboard
- Bootstrap UI
